# jetank_move_test

Jetank(로봇/서보) 제어 테스트를 위한 ROS2 기반 실험 레포입니다.

## 주요 내용
- 서보 초기화/제어 스크립트
- ROS2 토픽 기반 명령 publish/subscribe 테스트
- Jetank 제어 코드 및 설치 스크립트

## 빠른 시작
### 1) 저장소 준비
```bash
git clone <repo-url>
cd jetank_move_test
```

### 2) 설치
```bash
. install.sh
```

### 3) 실행 예시
```bash
cd code
python3 servoInt.py
```
